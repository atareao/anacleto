Minimal Language Server Protocol (LSP) client over stdio.

This module lets the agent query a language server (e.g. rust-analyzer, typescript-language-server) for hover, definition, references and diagnostics. It speaks JSON-RPC 2.0 with the standard LSP Content-Length framing over the server’s stdin/stdout.

The client is deliberately minimal and fault-tolerant: if the server cannot be spawned or does not respond, a clear error is returned rather than panicking.
