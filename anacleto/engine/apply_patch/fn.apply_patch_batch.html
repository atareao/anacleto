Expand description

Apply a batch of patch operations to the workspace.

All paths are validated before any change is made; if any path escapes the workspace the whole batch is rejected without touching the filesystem. When allow_external is true, paths may escape the workspace (the caller is responsible for having granted the fs.external permission).
