Batch file patching for the apply_patch tool.

The LLM sends a JSON batch of operations (add / update / delete) that are applied to files relative to the agent’s workspace. All operations are validated up-front (path traversal is rejected) and applied sequentially while preserving each existing file’s encoding (UTF-8 BOM and CRLF vs LF).
