Module tools 

Source
Expand description

Structured tools for the agent: read, grep, glob, webfetch, websearch, MCP resource tools and the lsp_query tool.

Each tool exposes a strict JSON schema via a xxx_tool_definition() function and an executor execute_xxx_tool(...) that returns Result<String, String>.
