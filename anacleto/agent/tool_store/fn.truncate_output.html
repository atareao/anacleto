pub fn truncate_output(content: &str, max_chars: usize) -> String
Expand description

Truncate content to at most max_chars characters.

If the content is already within the limit it is returned unchanged. Otherwise it is cut at max_chars and a marker noting the original length is appended so callers know the output was shortened.
