Configuration for spawning a subagent on-demand.

Fields§

Delegation depth of the spawned subagent (parent depth + 1).

§skills_override: Option<Vec<Skill>>

Pre-loaded skills to grant the subagent. If None, skills are loaded from the config’s skill paths.

§permissions_override: Option<Permissions>

Effective permissions for the subagent (parent ∩ child). If Some, overrides the permissions derived from config.permissions.
